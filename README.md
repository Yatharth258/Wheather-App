# Weather App 🌦️

A simple and responsive weather application that displays real-time weather information based on the user's search.

## Features

- 🌤️ Search weather by city
- 🌡️ Display current temperature
- 💨 Display weather conditions
- 📱 Responsive design
- ⚡ Simple and clean interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
